# evilork/tap

Homebrew tap for [ThermalBar](https://github.com/evilork/thermalbar), a free menu bar app for Apple Silicon Macs that shows CPU and GPU temperature, power, memory pressure, fans and thermal throttling.

```sh
brew install --cask evilork/tap/thermalbar
```

Update with `brew upgrade --cask thermalbar`. Uninstall with `brew uninstall --cask thermalbar`; add `--zap` to remove settings and history too.

Requirements: an Apple Silicon Mac (M1 or newer) and macOS 13 Ventura or later.
